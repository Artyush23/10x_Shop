# 10X Shop — 2–3 Minute Demo Script

## Flow

1. Open `https://10x-shop.vercel.app` and show the catalog, search, category pills, sorting, and pagination.
2. Open a product details page, show gallery/reviews/stock controls, and add the product to cart.
3. Open Cart, change quantity, apply valid promo `10X10`, and show the updated total.
4. Open Checkout as a guest, show redirect to Login, use the demo account, and return to Checkout.
5. Submit valid shipping details and show order confirmation with the cart cleared.
6. Open Orders, show status timeline, open details, reorder, and download the invoice.
7. Open Profile, save phone/profile data, toggle theme, and show logout/local-data controls.
8. Refresh `/products/5` directly to demonstrate the Vercel SPA rewrite.
