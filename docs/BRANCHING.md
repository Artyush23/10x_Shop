# Branching and commit map

The repository uses focused branches so a reviewer can follow the product journey:

- `feat/setup-and-tailwind` — tooling and design-system setup.
- `feat/architecture-and-state` — typed models, storage, and Context state.
- `feat/catalog-and-product` — API-driven catalog and product detail views.
- `feat/cart-and-checkout` — cart, validation, and checkout flow.
- `feat/orders-and-profile` — order history, tracking, reorder, and account settings.
- `docs/quality-and-delivery` — reports, debugging notes, compatibility, and delivery configuration.

All commits are created at implementation time; no historical timestamps or empty commits are used.
