# Contributing to 10X Shop

## Local setup

Use Node 20 or newer, install dependencies with `npm install`, then run `npm run dev`.

## Before opening a change

Run `npm run typecheck`, `npm run lint`, and `npm run build`. Keep UI text in English, keep API data typed, and prefer small focused commits using `feat:`, `fix:`, `perf:`, `docs:`, or `chore:` prefixes.

## Branches

Create feature branches from `main`. Do not commit secrets, generated `dist/` output, or credentials. Pull requests should explain what changed, why it changed, and how to verify it.
